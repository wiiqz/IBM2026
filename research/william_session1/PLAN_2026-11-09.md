## 3. Architecture

```
bulletin text ──► granite4 (Ollama) ──► typed JSON {identifiers[], packages[], paraphrase}  (pydantic-validated; LLM never writes SQL)
                                              │
                                              ▼
              Haystack pipeline: IBMDb2HybridRetriever (new) ──► ONE Db2 statement
                                              │      ├─ keyword leg: BM25 over TERM/IDF tables (bound JSON array via JSON_TABLE)
                                              │      ├─ vector leg: bare SELECT … ORDER BY VECTOR_DISTANCE … FETCH APPROX FIRST 200 ROWS (DiskANN)
                                              │      └─ RRF fusion with RANK() OVER(…)
SBOM (CycloneDX JSON) ──► JSON_TABLE ⋈ AFFECTED ⋈ ADVISORY (RCAC embargo) ──► affected packages
                                              │
                                              ▼
                granite memo ──► citation checker (every pkg/CVE must exist in result rows) ──► Streamlit 3-column UI / CLI
```

**Schema (schema `NEEDLE`).**
- **Tablespace:** 384-dim FLOAT32 vectors need an **8K-page tablespace and bufferpool**. The index key may be at most ¼ page, and 4K pages only allow 256 dims.
- **Tables:**
  - `ADVISORY(id PK, ecosystem, severity, embargoed SMALLINT, summary, doc CLOB)`
  - `CHUNK(chunk_id PK, advisory_id FK, text CLOB, emb VECTOR(384, FLOAT32) NOT NULL)`
  - `TERM(term, chunk_id, tf)` with index `(term, chunk_id)`
  - `IDF(term PK, idf)`
  - `CHUNK_LEN(chunk_id PK, len)`
  - `AFFECTED(advisory_id, pkg, version)`
  - `SBOM(id, doc CLOB)`
  - `EVAL_QUERY`
  - `EVAL_RESULT`
- **Load order:** load data **first**, then `CREATE VECTOR INDEX ix_chunk_emb ON chunk(emb) WITH DISTANCE COSINE`, then `RUNSTATS`. LOAD, REORG and TRUNCATE are restricted once the index exists.
- **Vector leg:** keep it a **bare single-table SELECT** so APPROX can't be silently dropped. Apply ecosystem filters and joins outside it.
- **Binding:** bind vectors as `VECTOR(CAST(? AS CLOB), 384, FLOAT32)`. No string-built SQL anywhere.

**Stack.**
- Db2 CE `icr.io/db2_community/db2:12.1.5.0` on Colima (vz + Rosetta, 6–8 GB).
- Python 3.12 via `uv`; `ibm_db` 3.3.0 also works on 3.14.
- `haystack-ai` + `ibm-db-haystack` 1.0.0.
- Ollama `granite-embedding:30m` (384-d) + `granite4` micro.
- Streamlit, pytest.
- Corpus: OSV advisories, PyPI + npm + a Maven slice that includes Log4Shell, **capped at ~20k chunks**, bulk-loaded.
